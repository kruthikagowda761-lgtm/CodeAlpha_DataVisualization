📊 Project Overview

The CodeAlpha Data Visualization project focuses on analyzing monthly business data and presenting meaningful insights using charts and graphs. This project uses Python libraries to visualize sales, profit, and customer trends across 12 months.

🎯 Objectives

- Transform raw data into meaningful visualizations.
- Analyze monthly sales and profit trends.
- Understand customer growth over time.
- Identify patterns and trends in business performance.
- Present data clearly to support decision-making.

🛠️ Technologies Used

- Python – Programming language
- Pandas – Data manipulation and analysis
- Matplotlib – Creating charts and graphs
- Seaborn – Statistical data visualization

📈 Dataset Information

The project uses monthly business data containing:

- Month: January to December
- Sales: Monthly sales revenue
- Profit: Monthly business profit
- Customers: Number of customers per month

✨ Features

- Displays the dataset and statistical summary.
- Calculates total sales and total profit.
- Analyzes customer counts across months.
- Creates visualizations to compare business performance.
- Helps identify monthly trends and patterns.

⚙️ Installation

1. Install Python

Install Python 3 from the official website:

https://www.python.org/downloads/

2. Install Required Libraries

Open the VS Code terminal in the folder containing "requirements.txt" and run:

python -m pip install -r requirements.txt

If the requirements file is unavailable, install the libraries directly:

python -m pip install pandas matplotlib seaborn

▶️ How to Run the Project

1. Open the project folder in Visual Studio Code.
2. Open the terminal.
3. Navigate to the folder containing "data_visualization.py".
4. Run:

python data_visualization.py

5. View the dataset summary in the terminal and the charts in the plot windows.

📊 Expected Output

The project displays business data analysis and charts illustrating monthly sales, profit, and customer trends. The exact charts depend on the visualizations implemented in the Python script.
